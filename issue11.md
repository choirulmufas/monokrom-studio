# Issue #011 - Working Process

## Objective

Add a clear Working Process section that explains how CM Studio moves a project from discovery to launch.

## Scope

- Create a data-driven `Process` component with six concise stages.
- Add the section after Why Choose Us.
- Use Lucide icons, semantic markup, and responsive process layout.
- Keep the desktop connector visual-only and remove it from smaller layouts.

## Process Stages

1. Discover
2. Plan
3. Design
4. Develop
5. Test & Refine
6. Launch & Grow

## Acceptance Criteria

- The section uses the existing `Container`, `Section`, `Heading`, `Card`, and `Badge` components.
- Each stage includes a number, icon, title, and short description.
- The process is horizontal on desktop and stacked on mobile without horizontal scrolling.
- No new dependencies or animation system are introduced.
- Existing sections remain unchanged apart from the required integration.
